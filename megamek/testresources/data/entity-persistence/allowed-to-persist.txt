# Entity and equipment fields that may keep their value from one battle into the next.
#
# Read by EntityPersistenceRegressionTest. Every non-static, non-transient field of the checked Entity and Mounted
# classes that is NOT listed here must be reset by Entity.clearGameState, which MekHQ calls between scenarios. The test
# changes each such field, runs clearGameState, and fails if the change survives.
#
# Format: <DeclaringClass>.<field>  <CATEGORY>  <reason>
#
#   KEEP        Design, configuration, damage, crew or a player's preference: carrying it over is intended.
#   GAME_RESET  Battle state that MegaMek itself resets when the next game starts or before it is next used (for
#               example in Entity.newRound, the server's per-phase reset, or when the unit is added to a game).
#   KNOWN_LEAK  Battle state that does carry over today and should be reset. Fix it, then delete the line.
#
# Adding a field to one of these classes? Reset it in clearGameState() if it only means something during a battle,
# otherwise list it here with the reason it may persist.
